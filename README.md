# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written for the
[make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

## The fortune

> The merge conflict you dread is two truths arguing over one line.

A merge conflict is a daily developer truth every engineer recognises —
and "two truths arguing" reframes it: neither side is wrong, both branches
were right in their own context, and the fight is over a single line of
code. One short balanced sentence, one breath, with a quiet twist on the
second read.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes the single
line to `/output/entry.txt`, after checking it is one line of 1–120
characters. Set `OUTPUT_PATH` to write somewhere else for a local test.
